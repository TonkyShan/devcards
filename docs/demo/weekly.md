# 周报 10-26 ~ 10-30
更新于 10-30 18:00

## 本周概览
- 订单导出功能上线：shop-api 支持按时间范围异步导出 CSV，web-console 同步加了导出入口和进度提示。
- 修复了大促期间库存扣减偶发超卖的问题，并补了并发测试。
- mobile-app 完成深色模式适配，启动耗时降低约 30%。

## shop-api
分支：main、feat/order-export、fix/stock-oversell

**新功能**
- 新增订单异步导出接口，支持按时间范围和状态筛选，结果生成 CSV 后通过站内信通知下载。
- 导出任务加了限流，单用户同时只能有一个进行中的任务。

**修复**
- 库存扣减改为 Redis Lua 原子操作，解决高并发下偶发超卖。
- 修复分页接口在 page_size 超上限时返回 500 的问题，改为返回 400 并提示上限。

**其他**
- 升级 Go 到 1.23，CI 增加竞态检测。

## web-console
分支：main、feat/export-ui

**新功能**
- 订单列表增加导出按钮和导出任务进度条。

## mobile-app
分支：main、feat/dark-mode

**新功能**
- 全局深色模式，跟随系统切换。

**其他**
- 首屏懒加载，冷启动从 2.1 秒降到 1.4 秒。
